# input/ — what the brand arrived with

The raw material the brand brings to the table, as-received. Nothing in here is production output.

- `01 brief (strategy).md` — the strategy brief. Always present before production runs; if the brand arrives without one, writing it is the first job of the engagement.
- `02 communications and content strategy.md` — if one exists.
- Any other as-received material (existing guidelines, prior decks, research), numbered in.
- `new-references/` — the inbox for raw references the principal or brand supplies mid-engagement. References graduate out of here when they get attached to an expression (folder in `03 expressions/`, ref into `refs/`, commentary into `feedback.md`). The inbox is not a production source — an agent building from a reference that never got an expression folder is skipping the system.

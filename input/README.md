# input/ — what the brand arrived with

The raw material the brand brings to the table, as-received. Nothing in here is production output.

- `01 brief (strategy).md` — the strategy overview digest. Written OUTSIDE the repo (paste `function/tools/strategy overview writer.md` into a separate chat with the brand's strategy materials) and dropped in at brand setup. The repo never compiles it. This is what the L-steps read — always present before production runs.
- `02 communications and content strategy.md` — if a separate comms/content overview is useful.
- Any other as-received material (existing guidelines, prior decks, research), numbered in.
- `new-references/` — inbox for raw references the user supplies mid-engagement. They graduate into the reference library `04 references/` (one md each: description + commentary + CDN), then get tagged to expressions. The inbox itself is not a production source.
- `explorations/` — staging for prior outputs when a brand arrives pre-explored (each carries the user's commentary + the prompt that made it). The first board pass forms expressions from the references + these explorations, and files each one into its expression's `explorations/`. Empty for a cold brand — correct, not a gap.

# input/ — what the brand arrived with

The raw material the brand brings to the table, as-received. Nothing in here is production output.

- `01 brief (strategy).md` — the compiled strategy overview: a digest of the brand's upstream strategy set (customer research, competitive set, product offering, brand strategy, communications, content strategy, creative). The full set lives in the DRAPER app, not the repo; an intake agent compiles this one digest from it (shape: `_strategy-overview-template.md`). This is what the L-steps read — always present before production runs.
- `02 communications and content strategy.md` — if a separate comms/content overview is useful.
- Any other as-received material (existing guidelines, prior decks, research), numbered in.
- `new-references/` — the inbox for raw references the principal or brand supplies mid-engagement. References graduate out of here when they get attached to an expression (folder in `02 expressions/`, ref into `refs/`, commentary into `feedback.md`). The inbox is not a production source — an agent building from a reference that never got an expression folder is skipping the system.

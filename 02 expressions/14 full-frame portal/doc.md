# Full-frame portal — expressions doc

**Version:** V1 · 2026-07-16 · Formed at second board pass, from the user's Expressions Catalogue v4 (Full-Frame) + the Ett Hem philosophy in the Creative Concepts doc
**Type:** brand expression (web layout philosophy)

## What it is

The immersive-entry philosophy: the homepage as a portal — a single full-bleed atmospheric frame with no initial scroll; sub-pages continuing screen-by-screen as immersive frames rather than long scrolling text pages; navigation subtle and secondary; media dominating the interface. The Ett Hem/Monteverdi lineage: start from radical simplicity, then add the brand's motion and interactivity on top.

## What the user likes

"The homepage acts as a portal using a single frame atmospheric video or image with no initial scroll… to ensure the user feels transported to the ranch immediately." Ett Hem's baseline: "extremely simple. Big illustration up top, then below it is a gallery of images and short video moment vignettes. That is it." And the build-up rule: "Start simple, then add" — motion, the map, the canvas, the horizontal stories are the additions.

## Control for (locked)

- **Imagery:** full-bleed, cinematic, atmospheric; media-dominant UI
- **Navigation:** minimal, subtle, secondary — never competing with the frame
- **Structure:** portal entry; screen-by-screen sub-pages over long scrolls
- **Mood:** transported, immersive, quiet

## Leave open — filled + cycled (variation space)

- **Portal medium (focus control):** atmospheric video / still / oversized illustration ([02](../02%20illustration%20language/doc.md), the Ett Hem move) — cycle
- **Tension with the negative-space stance ([04](../04%20negative%20space%20layout/doc.md)):** full-bleed portal vs. corner-weighted open field are two live hero philosophies — build both worlds, judge as worlds
- **What sits atop the frame (filled):** wordmark, one line, quiet nav — exact chrome open

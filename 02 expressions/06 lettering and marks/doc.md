# Lettering and marks — expressions doc

**Version:** V2 · 2026-07-16 · Amended same-session: the board's Logo Mark band (Mark · Lockup · Dir. 1 · Dir. 2) noted; glow integration and the land-scene badge added as open directions from the user's catalogue
**Type:** brand expression (logo / lettering territory)

## What it is

The lettering territory for Caven Ranch marks: heavy custom scripts with texture, italic script held inside rigid geometry, badge structures pairing formal serif with fluid script. Mid-century American vernacular — athletic, automotive, working — rather than luxury-resort polish. It exists as the exploration space for whatever wordmark or badge the brand ends up carrying; nothing is decided yet.

## What the user likes

The formal-versus-fluid tension, three ways: script distressed with stipple grain and a white inline; script disciplined by a sharp diamond; script playing second to a bold serif inside a badge. "The letterforms suggest mid-century motion and precision." The move of substituting an icon into a letterform. The Boston Whaler skiff kept in clean profile explicitly because "the unobstructed view preserves the forms needed for logo development."

## Control for (locked)

- **Lettering:** custom script letterforms with real weight; stipple-grain distress, white inline strokes; tight-tracked supporting type; fluid script contrasted against rigid structure (geometry or formal serif)
- **Logo (structure):** contained marks — badge, diamond, rounded container; horizontal lockups; icon-into-letterform substitution as a live move
- **Mood:** mid-century American vernacular — athletic, automotive, precise; nostalgic without pastiche

## Leave open — filled + cycled (variation space)

- **Structural fork (focus control — build as distinct variations):** (a) freestanding distressed script wordmark; (b) script inside hard geometry (diamond or equivalent); (c) horizontal badge with serif lead + script secondary; (d) circular land-scene badge — the user's catalogue carries an example: river/cypress/limestone scene inside a double-lined circle, "CAVEN RANCH" arched above, "HILL COUNTRY" below
- **Mark subject (cycled):** the Boston Whaler skiff profile is preserved for logo development; the animal character is a candidate (open in [01 coyote character](../01%20coyote%20character/doc.md)); the land itself (the badge scene); pure lettering with no pictorial mark is equally live
- **Color (filled from [05 palette](../05%20palette/doc.md)):** the reference marks run red/cobalt/orange — whether a Caven mark adopts palette accents (#8B391D terracotta) or its own registers is open
- **Glow integration (open treatment, from the user's catalogue):** the mark/typography emitting a soft warm tungsten glow over moody dusk photography, "like a lit sign" — mirroring cabin interior and path lighting
- **The board carried two mark directions side by side** (Mark · Lockup · Dir. 1 · Dir. 2) — how much of either survives the walk-away is the user's call; treat as seasoning per settled.md

# Horizontal scroll narrative — expressions doc

**Version:** V1 · 2026-07-16 · Formed at second board pass, from the user's Creative Concepts doc + the horizontal editorial reference + the old catalogue's time-sequence concept
**Type:** brand expression (layout / web mechanic — the story surface)

## What it is

The sideways-reading surface: when a visitor clicks into a specific story, the page scrolls horizontally instead of vertically — text, photos, graphic elements, and illustration paced along a fixed-ratio timeline. The same mechanic carries the time-of-day strip (the identical locked-off view at dawn, midday, golden hour, night, swiped through). It exists because the family stories are the brand's narrative depth, and a horizontal read makes a story feel like a told thing rather than a page.

## What the user likes

"Large serif titles and section numbers anchor the narrative, while offset text and varying image scales create a nonlinear, magazine-like timeline on a muted warm ground." Illustration carrying historical moments "where illustration might carry more weight and feel more honest than trying to create photorealistic imagery of events from the 1800s and early 1900s." The proving-out can be "a couple of frames showing what sections of a story would look like" — not the built interaction.

## Control for (locked)

- **Time:** paced reveal along the horizontal axis; each step gives something new; section numbers/titles as wayposts
- **Type:** large serif titles and numerals as anchors; offset supporting text
- **Imagery:** varying scales along the strip; illustration for pre-photography eras (per the user's honesty argument)
- **Ground:** muted warm ground per [05 palette](../05%20palette/doc.md)

## Leave open — filled + cycled (variation space)

- **Content mode (focus control):** (a) family story told sideways; (b) time-of-day locked-view strip ("Same view. Same chair. A different world every few hours." — the old catalogue's take); (c) arrival-drive sequence
- **Mix of media per story (filled):** archival photos, illustration, artifacts — from `03 media/` + [02](../02%20illustration%20language/doc.md) + [03](../03%20heritage%20ephemera/doc.md)
- **Deliverable depth:** static frames proving sections vs. built interaction — the user set frames as the near-term bar

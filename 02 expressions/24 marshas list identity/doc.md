# Marsha's List identity — expressions doc

**Version:** V1 · 2026-07-17 · New expression off the 2026-07-17 reference batch (scattered-composition-with-central-serif, stamped-fabric-gyotaku-illustration, vertical-typography-and-illustration-alignment)
**Type:** brand expression (sub-brand identity system)

## What it is

A dedicated identity system for Marsha's List — the ranch's naturalist / conservation record of the plants, animals, and land. It has three parts: an illustration language that reads like ink pressed into woven fabric (gyotaku / fabric-stamp — imperfect type that follows the weave, subjects bisected so the back half wraps to the top and the front half sits at the bottom); a scattered, open, non-grid canvas of small items anchored by a central small-scale serif block; and an identifier / mark for "Marsha's List" itself, which the user explicitly asked for and which was never made. It exists so the conservation content has its own designed voice — nature, plants, animals, conservation — distinct from the main brand yet clearly of the ranch. This doc owns the identity (mark + illustration language + texture + naming); the scattered-canvas layout mechanics live in [13 infinite canvas](../13%20infinite%20canvas/doc.md) — cross-linked, not duplicated here.

## What the user likes

The stamped-on-fabric illustration, explicitly for this: "Imagine this on Marshas' list." The substrate that is not paper: "It doesn't look like paper. It looks more like fabric and more like it's stamped on fabric." The bisected wrap-around subject: "how it's cut out from the top, how it's continuing on the fish... the back half of it, is on the top and the front half is at the bottom." The imperfect type that follows the surface: "the text is not perfect, so I'm following the fabric." And it is subject-agnostic — "it's not about subject matter. It will be whatever it is that's pressed on this fabric." The scattered canvas as the layout idea: "Marshas list idea: I like the illustration and use very short, small text in the middle... how the items are scattered out, quite open, with good colors... I can imagine there are more items on a page." And the vertical type-following-illustration move as a way to set the name and a short blurb: "Imagine that says Cavan, and then it's just short information... It's vertically flipped like that, so it's following the illustration." The one firm correction on that ref: the illustration style and color must be the brand's own — "I don't want this watery color... it wouldn't be blue... It would need to be like our illustration style."

## Control for (locked)

- **Illustration language:** stamped / gyotaku — ink pressed into a heavy woven-fabric substrate with visible weave and ink-spread, NOT sitting on paper; subjects bisected with a wrap-around cut (back half top, front half bottom) — provenance: user, "stamped on fabric," "the back half of it, is on the top and the front half is at the bottom" (stamped-fabric-gyotaku-illustration)
- **Typography (within the stamp):** intentionally imperfect type that follows the ripples/weave of the fabric — provenance: user, "the text is not perfect, so I'm following the fabric" (stamped-fabric-gyotaku-illustration)
- **Layout register:** scattered, open, non-grid canvas of small items with a central small-scale serif block and generous negative space — provenance: user, "items are scattered out, quite open... short, small text in the middle" (scattered-composition-with-central-serif). Layout mechanics owned by [13 infinite canvas](../13%20infinite%20canvas/doc.md).
- **Content domain:** nature, plants, animals, conservation — the naturalist record; facts drawn only from [06 knowledge](../../06%20knowledge/) (Marsha, the species, the conservation record) — provenance: task framing + settled.md (facts from knowledge only)
- **Color & illustration style:** the brand's own illustration style and palette, never the ref's watery blue — provenance: user, "it wouldn't be blue... like our illustration style" (vertical-typography-and-illustration-alignment); cycle within the active color direction ([05 palette](../05%20palette/doc.md))
- **Type is ink:** any set type stays near-black / ink, mixed case, never uppercase, never a palette-green — provenance: settled.md

- **Vertical type usage:** the name-following-the-illustration orientation as one option for setting "Caven" / "Marsha's List" plus a short blurb — filled against [06 lettering and marks](../06%20lettering%20and%20marks/doc.md) and [21 typography](../21%20typography/doc.md).

## Negative

- **Not a naturalist's-desk / scrapbook.** Pressed flowers, scanned specimens, plant-illustration-on-old-paper, torn paper, handwritten notes are all killed — they read as a museum exhibit. Marsha's List is contemporary. — provenance: settled.md (Open questions, "Marsha's List is contemporary... NOT a naturalist's-desk/scrapbook")
- **Not paper.** The illustration substrate is fabric, explicitly not paper. — provenance: user (stamped-fabric-gyotaku-illustration) + settled.md (no old-paper)
- **Not the ref's watery blue / not the ref's illustration style.** The color and style must be the brand's own. — provenance: user (vertical-typography-and-illustration-alignment)
- **Not the botanical linocut of the scattered-canvas ref.** That ref's illustration is a high-contrast linocut; linocut/woodblock is killed brand-wide — take the scattered layout and central-serif idea, not the linocut technique. — provenance: settled.md (Direction, "off the table for illustration: ...woodblock/linocut")
- **Never uppercase, never green type.** — provenance: settled.md.

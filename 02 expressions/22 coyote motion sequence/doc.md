# Coyote motion sequence — expressions doc

**Version:** V1 · 2026-07-17 · New expression off the 2026-07-17 reference batch (sequential-motion-frame-pattern, sequential-motion-silhouette-layout, hand-drawn-sequential-illustration-layout)
**Type:** brand expression (recurring graphic device / motion-and-pattern system)

## What it is

The coyote — and, secondarily, other property subjects like fish, the river, or stars — rendered in repeated sequential frames of motion, chronophotography-style, so a single character reads its own gait phase by phase and becomes a rhythmic repeating graphic. The frames do structural work across the site: a pattern fill, a divider that breaks up dense text between sections, a list-anchor down the left edge of an experiences or day-trip index, and potentially the preloader animation itself. It is the coyote character put into motion and multiplied — one animal doing the work of a texture, a rule, and a rhythm, so the brand's animal shows up as structure rather than as a labeled mascot.

## What the user likes

Turning a single coyote into a pattern out of its own movement: "Creating a pattern from the Coyote, kinda like different frames of it." Using those frames functionally, not decoratively for its own sake: "Using that different frames of coyotes in layouts and in between texts and just breaking up things using it." The list layout where sequential illustrations anchor descriptive text down a column — "I do like this layout" — read as the experiences/day-trips index: "different places you can go to in the area," the "different parts of the day," "getting to the cabins," rendered "in a nicer, different type of layout that you wouldn't see anywhere else." The subject rotates by context — "stars, fishes, the river," the coyotes, the ATVs, getting to the cabins — one device, many property subjects. High-contrast, simplified silhouettes are what let the frames repeat and still read.

## Control for (locked)

- **Graphic device (structure):** a single subject repeated across sequential frames of one continuous motion (gait phases / chronophotography), read left-to-right or gridded, so the repetition itself is the graphic — provenance: user, "different frames of it," "different frames of that illustration" (sequential-motion-frame-pattern, hand-drawn-sequential-illustration-layout)
- **Structural role:** functional first — pattern fill, text divider between sections, and list-anchor down a column; not ornament dropped in for its own sake — provenance: user, "in between texts and just breaking up things using it" (sequential-motion-silhouette-layout); "I do like this layout" for the anchored list (hand-drawn-sequential-illustration-layout)
- **Rendering:** high-contrast, simplified silhouette forms — the reduction is what lets a frame repeat and still read at small scale — provenance: reference visual + user's read across all three refs
- **Subject:** the coyote is the primary; the animal is always an actual coyote, never anthropomorphized or costumed — provenance: settled.md (Direction, "the coyote is always an actual coyote — never wearing clothing or human accessories")

## Scenarios (build worlds, judged against each other)

- **Which subject fills the sequence:** the coyote is primary, but the device is explicitly meant to rotate by context — the user names "stars, fishes, the river," the coyotes, "the ATVs," "getting to the cabins," "different parts of the day." Same device, different subject per placement; build the coyote world plus at least one property-subject world (fish or river) and judge them as worlds. Non-anthropomorphized coyote is the one fixed constraint across all.

## Leave open — filled + cycled (variation space)

- **Placement / structural role (focus control — these are forks, build as distinct variations):** (a) full pattern fill / repeating tile; (b) horizontal divider strip between two text sections; (c) list-anchor running down the left of an experiences / day-trip index, descriptive copy to the right; (d) the preloader motion itself, where the gait phases literally animate. Cross-links: [08 preloader](../08%20preloader/doc.md), [09 site motion](../09%20site%20motion/doc.md), [20 social content system](../20%20social%20content%20system/doc.md).
- **Frame count and cadence:** how many phases, how tight the spacing, whether the rhythm is even or staccato — cycle. The silhouette ref reads as a "staccato rhythm of motion frames"; the pattern ref as a tight even grid.
- **Grid vs. row vs. scattered:** tight geometric grid (pattern mode) vs. single horizontal row (divider mode) vs. anchored column (list mode) — determined by placement.
- **Color of the silhouettes and ground:** cycle within the active color direction ([05 palette](../05%20palette/doc.md), rotate one direction at random per update per settled.md). Type that ever sits beside the frames stays ink / near-black, mixed case.
- **Motion styling in the animated modes:** how the phases advance, loop, or blur — filled at build against [09 site motion](../09%20site%20motion/doc.md) and [19 texture and print artifacts](../19%20texture%20and%20print%20artifacts/doc.md) for any print-artifact grain on the silhouettes.

## Negative

- **No prices in the list layout.** The hand-drawn ref shows priced items; the user: "I do like how they did the prices or something here, but we wouldn't do the prices." — provenance: user (hand-drawn-sequential-illustration-layout)
- **No red dots / colored bullet markers as the list anchor.** — provenance: user, "I don't like the red dots on the left" (hand-drawn-sequential-illustration-layout)
- **Not vintage lithograph / aged-paper / archival.** Two ref descriptions read "vintage lithographic print style" and "aged paper"; that register is off the table brand-wide — the coyote here is a contemporary high-contrast silhouette, not an old natural-history plate. — provenance: settled.md (Direction, "the whole brand must read CONTEMPORARY, never archival/heritage/scrapbook")
- **Never a labeled mascot.** The coyote is never announced or captioned as a brand character where these frames appear. — provenance: [01 coyote character](../01%20coyote%20character/doc.md) locked presence rule.

# Navigation and header — expressions doc

**Version:** V1 · 2026-07-16 · Formed at second board pass, from the reference library + the full-frame philosophy; named as its own territory at the user's direction (chat, 2026-07-16: web-specific systems including headers)
**Type:** brand expression (web system)

## What it is

The site's wayfinding chrome: the header bar, the menu, and how present they are. The reference direction is editorial — a full-height sidebar menu with high-contrast serif primary items and structured sans metadata; corner-aligned navigation on pages; the full-frame philosophy wants it "subtle and secondary." It exists because every page carries this system, and generic nav is where brands quietly die.

## What the user likes

"A clean, editorial mobile navigation system featuring a high-contrast serif for primary menu items. The full-height sidebar uses generous space, a top-right close control, and a structured sans serif for secondary links and metadata." Corner navigation as part of the print-journal grammar across the layout references.

## Control for (locked)

- **Navigation:** subtle and secondary against the content; corner-aligned; the open menu is its own composed surface (full-height, generous space), not a dropdown
- **Type:** serif primary items, structured sans secondary/metadata registers (ties to [21 typography](../21%20typography/doc.md))

## Leave open — filled + cycled (variation space)

- **Menu surface (focus control):** full-height sidebar / full-screen takeover / minimal corner links — cycle
- **Header density:** wordmark-only vs. wordmark + links vs. hidden-until-summoned — cycle per the portal tension ([14](../14%20full-frame%20portal/doc.md))
- **The site pages it must hold (filled from the user's docs):** home, lodgings, property experience, stories, Marsha's List

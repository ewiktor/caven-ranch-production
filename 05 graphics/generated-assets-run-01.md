# Generated graphics — Paper run 01 (2026-07-16)

All images generated with Nano Banana Pro (Gemini 3 Pro Image) during the expression-exploration Paper run, mirrored here from `09 output/paper-run-01/img/`. These are **exploration assets**, not finalized brand marks — a finalized mark earns its own `_graphic-doc-template.md` doc. Naming: `NN-<slug>-vN.png`; `-feather`/`-cropped`/`-crop`/`-transparent`/`-clean` are post-processed variants; `-check` are working intermediates. Anti-AI-look prompting throughout (physical-medium description: brushed ink, riso off-registration, clay/wood/stone texture).

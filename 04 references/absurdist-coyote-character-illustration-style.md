# Absurdist Coyote Character Illustration Style

## Description

This reference establishes a template for a consistent brand character by placing a wild animal in a domestic, highly stylized setting. The illustration uses a painterly, fine-art approach with visible brushstrokes and a muted, sophisticated color palette to elevate the subject beyond a simple mascot. The composition relies on bold geometric patterns, like the vertical red and white stripes, to create a high-contrast backdrop that frames the character in an unexpected, slightly absurd context. This treatment suggests a way to render a coyote with dignity and personality while maintaining a distinct, non-photographic illustrative edge.

# Split-Screen Layout with Card Overlay

## Description

This layout utilizes a vertical split-screen composition where a textured card element is overlaid on the left side, creating a layered depth against a background scene. The right side features a structured typographic hierarchy including a top-aligned header with a small illustration, a central justified text block, and a footer defined by a horizontal rule with split date markers. The design emphasizes a clean, editorial arrangement of information using varying text scales and graphic dividers to organize content.

# Minimalist Serif Typography and Sidebar Menu

## Description

This reference showcases a clean, editorial-style mobile navigation system featuring a high-contrast serif typeface for primary menu items. The layout utilizes a minimalist full-height sidebar with a 'Close' trigger aligned to the top right, creating a spacious and functional hierarchy. The typography transitions from large, elegant serifs for main categories to a structured sans-serif for secondary utility links and metadata.

# Minimalist Topographic Property Map Style

## Description

This graphic approach utilizes a high-contrast satellite relief isolated against a stark, textured paper background to create a premium editorial feel for property mapping. The map features a desaturated, earthy color palette of deep forest greens and ochre, emphasizing natural terrain over man-made infrastructure. Minimalist callouts use fine hairline leaders and elegant serif typography to provide data points without cluttering the visual field. The composition relies on significant negative space to frame the subject, treating the geographic area as a singular, sculptural object.

## User context

Satellite relief is isolated against a textured paper field and treated as a sculptural object. Desaturated forest green and ochre emphasize terrain, while hairline leaders and serif labels communicate information without clutter.

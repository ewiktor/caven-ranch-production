# Vertical Typography and Illustration Alignment

## Description

This reference demonstrates a unique layout where the primary typography and descriptive text are rotated 90 degrees to run vertically alongside the central illustration. The text block is positioned to follow the vertical axis of the subject, creating a structural relationship between the brand name and the visual element. This orientation forces a shift in the viewer's perspective, making the information feel like a secondary, integrated label rather than a standard header.

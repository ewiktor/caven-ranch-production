# Vintage Script Logo with Distressed Texture

## Description

This logo mark direction utilizes a heavy, custom script typeface with a distinct stipple-grain texture to evoke a nostalgic, athletic aesthetic. The primary wordmark features a thick red stroke with a subtle white inline, while the secondary sans-serif typography is tightly tracked and positioned to create a balanced lockup. A clever iconographic substitution replaces the tittle of the 'i' with a pickleball, integrating the sport's identity directly into the letterform.

# Vertical Stacked Editorial Layout

## Description

This layout features a structured vertical hierarchy where a square-format image is anchored by two distinct levels of typography directly beneath it. A line of small, wide-tracked sans-serif subtext provides a delicate horizontal anchor, followed by a bold, large-scale display heading that establishes a strong visual base. The composition utilizes generous white space and thin hairline borders to create a clean, editorial aesthetic that feels both modern and grounded.

# Heritage Serif UI with Map Overlays

## Description

This interface utilizes a sophisticated blend of traditional serif typography and modern functional overlays to create a 'new heritage' aesthetic. The layout features a clean search modal with illustrative map thumbnails that provide a contemporary way to navigate property regions, while the property detail page uses high-contrast serif headers and clean sans-serif body text for a balanced, editorial feel. The composition emphasizes a structured hierarchy where large-scale property imagery is grounded by classic typographic styling and functional UI elements.

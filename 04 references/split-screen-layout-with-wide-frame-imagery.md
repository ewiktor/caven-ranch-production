# Split-Screen Layout with Wide-Frame Imagery

## Description

This layout utilizes a strict 50/50 vertical split-screen composition that juxtaposes a full-bleed environmental photograph with a structured editorial column. The right-hand side features a secondary image with an ultra-wide aspect ratio, creating a 'letterbox' effect that emphasizes horizontal architectural lines within the sage green canvas. This wide-frame placement allows for significant negative space above and below, providing a clean area for large-scale serif typography and multi-column project metadata. The relationship between the full-height left image and the inset wide-frame right image establishes a sophisticated visual hierarchy for architectural storytelling.

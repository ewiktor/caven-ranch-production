# Scattered Composition with Central Serif

## Description

This layout utilizes a vast amount of negative space to anchor a central, small-scale serif typography block and a singular botanical linocut illustration. Supporting imagery is distributed across the periphery in an asymmetrical, 'scattered' arrangement that feels organic and open rather than grid-locked. The color palette relies on a warm, desaturated cream base that allows the high-contrast black ink and muted photographic tones to breathe.

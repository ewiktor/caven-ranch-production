# Hand-Drawn Serif Centered Layout

## Description

The layout utilizes a strict center-aligned hierarchy, placing high-contrast white typography directly over a complex, textured background to create a focal point. The typographic pairing combines a bold, organic hand-drawn display face with a traditional high-contrast serif, establishing a balance between artisanal craft and professional structure. This vertical composition uses the subject's form as a natural canvas, ensuring the text remains the primary informational layer despite the busy patchwork patterns beneath.

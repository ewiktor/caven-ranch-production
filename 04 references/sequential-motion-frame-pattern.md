# Sequential Motion Frame Pattern

## Description

This reference demonstrates a rhythmic pattern created through sequential chronophotography, where individual frames of a subject in motion are arranged in a repetitive grid. The composition uses the incremental changes in the subject's silhouette to create a sense of fluid movement and visual texture across the layout. This approach allows for a single character to be transformed into a complex, repeating graphic element through the use of distinct gait phases.

# Split Layout with Overlapping Illustration

## Description

This layout utilizes a clean vertical split, balancing a high-contrast serif headline on the left with a lifestyle photograph on the right. A playful line-art illustration overlaps the primary text block to create depth, while a secondary block of small-scale body copy anchors the bottom left corner. The right side features a transparent logo overlay, demonstrating how brand names can be integrated directly into the photographic subject matter.

# Inset Frame Image Cut-outs

## Description

This graphic approach utilizes a central frame cut-out to overlay a secondary, detailed perspective onto a primary silhouette or subject. In the top example, a high-contrast Doberman silhouette is interrupted by a rectangular window showing a detailed, textured close-up of the same subject, creating a non-linear spatial relationship. The bottom example uses a horizontal rectangular inset to disrupt a vertical portrait, layering a different narrative scene over the central figure. This technique relies on sharp geometric boundaries and stark tonal shifts to create a 'picture-in-picture' effect that challenges traditional composition.

## User context

A rectangular inset interrupts a primary subject or silhouette to reveal a second, more detailed perspective. Sharp boundaries and tonal contrast create a picture-in-picture effect that disrupts conventional spatial relationships.

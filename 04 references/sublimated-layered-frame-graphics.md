# Sublimated Layered Frame Graphics

## Description

This graphic approach utilizes a sublimation technique where multiple sequential frames of a horse in motion are layered with varying opacities to create a sense of temporal depth. The central frame is anchored by a high-contrast halftone dither pattern, while peripheral frames fade into the textured paper substrate, suggesting a ghosting or motion-blur effect. Technical printer marks, crop brackets, and registration dashes frame the composition, reinforcing the aesthetic of a work-in-progress or a physical print proof. The typography at the base mirrors this layered logic, with overlapping sans-serif text strings that create a rhythmic, stuttered visual readout.

## User context

Sequential horse frames are layered at different opacities to communicate motion and time. Halftone dithering, ghosted frames, crop marks, registration details, textured paper, and overlapping type create a print-proof aesthetic.

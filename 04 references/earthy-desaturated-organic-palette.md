# Earthy Desaturated Organic Palette

## Description

This palette features a sophisticated trio of desaturated, nature-inspired tones including a muted sage green (#969582), a warm terracotta sand (#B78962), and a dusty slate blue (#97A2AD). The colors are unified by a consistent low-saturation profile and a shared mid-tone value, creating a harmonious and grounded aesthetic. The interaction between the warm ochre and the cool slate provides a balanced contrast that feels organic rather than synthetic.

# Vintage Racing Badge Logo

## Description

This logo mark direction utilizes a high-contrast horizontal badge layout, layering a bold red serif typeface over a secondary script font to create a sense of heritage and speed. The composition is anchored by a graphic checkered flag motif that integrates seamlessly with the typography, all contained within a rounded rectangular dark container. The interplay between the structured serif and the fluid script provides a dynamic tension characteristic of classic automotive branding.

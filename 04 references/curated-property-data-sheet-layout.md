# Curated Property Data Sheet Layout

## Description

This layout features a structured property information table at the bottom, balanced by a top-heavy header containing dual-logo placement on the left and a pinned photographic reference on the right. The design utilizes a clean, editorial grid that separates high-level branding from granular property details through a horizontal rule and a four-row data table. The combination of serif typography for branding and handwritten script for data entries creates a personalized, 'insider' feel for curated lists.
